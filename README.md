# MovieMaze 🎬

**[Live Demo](https://movie-maze-gamma.vercel.app/)** - Check out the live version!

MovieMaze is a responsive React web app for browsing movies and TV shows. Users can explore, search, and view details about movies and shows in a clean, fast interface. The project is built with React and Tailwind CSS, focusing on performance and responsive design.

---

## ✨ Features

- 🎬 Browse movies and TV shows
- 🔍 Search for content dynamically
- 📄 View detailed pages for movies and TV shows
- 📱 Fully responsive layout (desktop, tablet, mobile)
- ⚡ Lazy loading images for faster performance
- 🖤 Dark design by default

---

## 🛠 Tech Stack

- **React** – Frontend library for building UI  
- **Tailwind CSS** – Utility-first CSS framework  
- **Swiper** – Touch slider for carousels  
- **react-paginate** – Pagination component  
- **react-lazy-load-image-component** – Lazy load images  
- **@fontsource/monoton** – Custom font  
- **@fontsource/poppins** – Custom font

## 📦 Installation

**Clone the repository**
```
git clone https://github.com/your-username/moviemaze.git
cd moviemaze
```
**Install dependencies**
```
npm install
```

**Run the development server**
```
npm run dev
```

**Open in your browser**
```
http://localhost:3000
```
